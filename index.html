有 AI Agent？复制下面这段话发给它就能自动投稿

              

                如果你正在使用 豆包工作、Workbuddy、Codex、Claude Code、Antigravity、Cursor、OpenClaw 等具备文件操作或 Git 能力的 AI Agent，不需要手动研究目录结构，把下方提示词和你的文件（皮肤 .kurocat、饰品透明 PNG 或键盘配色想法）一起发给它，Agent 会自动完成 Fork、Star、Clone、打包、规范校验并提交 Pull Request。
              

            


            

              

                
                
                
                
              

              
            


            

          


          


          
          

            
给 Agent 与开发者的投稿规范

            

              KuroCat 广场采用 每件作品独立目录 的零冲突架构：所有投稿只需新增自己的子目录，严禁手动修改 index.json。提交 PR 后，GitHub Actions 会自动运行 node scripts/validate-community.mjs 校验格式与体积；合并进 main 后自动重建索引并部署到 GitHub Pages。
            


            

              

                

                  
1. 投稿皮肤

                  community/<slug>/
                

                
    
                  
  • skin.kurocat（必填）：符合 v1 规范的皮肤 JSON，体积 ≤ 2 MB。
    • 
                  
  • meta.json（必填）：包含 title、author、authorUrl（可选）、description（≤ 180 字）、tags（1–6 个）、createdAt（YYYY-MM-DD）。
    • 
                  
  • preview.gif / .webp / .png（可选，≤ 5 MB）：展示在皮肤广场卡片上；不上传则自动使用实时 2.5D 互动渲染。
    • 
                

                
{
  "title": "草莓奶油三花猫",
  "author": "你的昵称",
  "authorUrl": "https://github.com/your-id",
  "description": "粉白软萌三花配浅蓝瞳，支持直接二创改花斑。",
  "tags": ["三花猫", "原创配色", "软萌"],
  "createdAt": "2026-11-24"
}

              


              

                

                  
2. 投稿饰品

                  community-accessories/<slug>/
                

                
    
                  
  • accessory.png（必填）：透明底 PNG，体积 ≤ 1 MB，尺寸 ≤ 1024×1024（推荐 2× 透明贴纸）。
    • 
                  
  • meta.json（必填）：除通用字段外，必须声明 anchor（headTop / face / neck / tailTip）及默认位置参数 offsetX、offsetY、scale、rotation。
    • 
                  
  • preview.gif / .png（可选）：若不提供则直接展示 accessory.png。
    • 
                

                
{
  "title": "招财小鱼发卡",
  "author": "你的昵称",
  "authorUrl": "https://github.com/your-id",
  "description": "卡在耳边的元气小鱼干发卡。",
  "anchor": "headTop",
  "offsetX": 22,
  "offsetY": -4,
  "scale": 0.82,
  "rotation": 14,
  "tags": ["头饰", "可爱"],
  "createdAt": "2026-11-24"
}

              


              

                

                  
3. 投稿键盘

                  community-keyboards/<slug>/
                

                
    
                  
  • keyboard.json（必填，≤ 128 KB）：formatVersion: 1，含 colors 对象（mouseBody、mouseBorder、wheel、base、deck、key、keyBorder、accent 均为 #RRGGBB，外加布尔值 darkText）。
    • 
                  
  • meta.json（必填）：包含 title、author、description、tags、createdAt。
    • 
                  
  • preview.png / .gif（可选）：不提供则自动实时渲染 2.5D 键盘与鼠标预览。
    • 
                

                
{
  "formatVersion": 1,
  "name": "樱花奶盖 65%",
  "author": "你的昵称",
  "colors": {
    "mouseBody": "#FFF6F8",
    "mouseBorder": "#6B4252",
    "wheel": "#F28BA8",
    "base": "#5C3A48",
    "deck": "#7D5264",
    "key": "#FFF9FA",
    "keyBorder": "#EBC8D4",
    "accent": "#F28BA8",
    "darkText": true
  }
}

              

            


            

              
提交 PR 前的本地校验命令（Node.js 18+，零依赖）

              
node scripts/validate-community.mjs && node scripts/build-plaza-index.mjs

              
注意：slug 目录名仅允许小写英文字母、数字和连字符（2–49 字符），且只提交你新增的子目录文件，不要把本地生成的 index.json 变动混进 PR（或按 CI 提示保持干净）。

KuroCat v1.6.0 更新日志

        

        
      

      

        

          
          

            全可见区「一叠透明纸」像素图层引擎
            
12 个部位统一升级为透明图层，打开模板或皮肤自动光栅化；新增裁剪蒙版、Alpha 锁定、正片叠底/滤色/叠加混合模式、多画笔、油漆桶、矩形/套索选区变换与导入图片一键去白底。

          

        

        

          
          

            真 3D 球面头部 + 四肢/尾巴弯曲贴图
            
头部转头与俯仰采用 3D 球面逆映射并带缓存，手臂、后腿、尾巴及拎脖子采用弯曲条带网格贴图；支持独立眼球贴图与鼻/嘴直绘，爪尖与坐姿后爪不被默认色块遮挡，工坊、官网与 macOS / Windows / Linux 桌宠四端同步。

          

        

        

          
          

            全屏大画板 + 悬浮透明小猫
            
创作画板全屏展开，取消预设动作栏；预览小猫化为无边框透明桌宠，可任意拖到网页角落、拖拽缩放尺寸或收起为迷你气泡。

          

        

        

          
          

            .kurocat v2 导出与分层工程持久化
            
兼容 1.4.0–1.5.x 皮肤，自动写入最低兼容版本 minAppVersion: "1.6.0"，支持浏览器 IndexedDB 自动保存与 .kurocat-layers.json 工程导入导出。

          

        

      

      

        需要 KuroCat 1.6.0+ 桌宠体验全部图层皮肤效果
